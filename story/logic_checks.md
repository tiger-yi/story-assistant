## 2. 规则逻辑自洽性 (Rule Consistency)

- **【规则 1】**：物理攻击必须依托载具
  - **漏洞/利用点**：如果车坏了怎么办？（伏笔：主角随身带扳手，扳手也是改装过的）。
- **【规则 2】**：直播间打赏可具现化
  - **漏洞/利用点**：观众打赏什么就有什么，但仅限改装零件或buff，不能直接给神器。

## 3. 频率与节奏审计 (Pacing Check)

- [ ] **反转频率合理吗？** 每一章都有物理手段的新花样（撞、碾、照、喷）。
- [ ] **爽点给够了吗？** 只要反派装逼，立马物理打脸，绝不隔夜。

## 4. 情绪与冲突审计 (Emotion & Conflict Check)

- [ ] **情感底色正确吗？** 兄妹羁绊（唯一的软肋） + 暴躁输出（坚硬的铠甲）。
- [ ] **拒绝强行洗白：** 陈子峰必须死，而且要被吓死。
- [ ] **冲突等级足够吗？** 从撞鬼（小怪）到撞人（恶少）到撞神（邪修）。
